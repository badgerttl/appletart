# Distribution icons

Official, unmodified distribution assets, served locally:

- Ubuntu Circle of Friends: https://assets.ubuntu.com/v1/ce518a18-CoF-2022_solid+O.svg (Canonical Ltd.). Brand resources: https://design.ubuntu.com/resources
- Kali Linux dragon: https://www.kali.org/images/favicon.svg (OffSec). Press pack: https://gitlab.com/kalilinux/documentation/press-pack

Ubuntu and Kali Linux marks belong to their respective owners.

VM control icons are original AppleTart SVG artwork, drawn in the project.

`appletart.svg` is the original AppleTart app mark, shared by the sidebar and browser favicon.

Sidebar icons use the Lucide server, layers, and settings SVGs, vendored from https://github.com/lucide-icons/lucide on 2026-10-03. They are embedded inline in index.html to inherit the theme color. The license and Feather attribution are preserved in LUCIDE-LICENSE.md.

The log copy and download icons also use Lucide shapes, covered by the same license.

RHEL (Red Hat), Fedora, Debian, Rocky Linux, Apple/macOS and generic Linux icons use [Simple Icons](https://github.com/simple-icons/simple-icons), retrieved 2026-10-03. Their SVG geometry is preserved and platform colors are applied. Simple Icons is distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md); trademarks remain the property of their respective owners. Ubuntu Runner uses the Ubuntu icon.
